BEFORE WE START

A few practical
questions.

What should I share in an inquiry?

The business question, data sources, expected deliverable and any target date. Start with a description or a redacted sample; we can agree how to handle sensitive data before you share it.

How do you estimate the scope and cost?

After reviewing the inputs, complexity, access requirements and acceptance criteria. There is no fixed price or delivery promise before we define the work together.

Can we start with an existing report?

Yes. Describe what is difficult to use or maintain, and what you want it to do. An initial review can help define whether the work is a focused improvement or a wider rebuild.

What about data engineering or machine learning?

My portfolio includes database, ETL and machine-learning studies. If your project needs these capabilities, we can review the requirements and decide whether they fit the problem and scope.
