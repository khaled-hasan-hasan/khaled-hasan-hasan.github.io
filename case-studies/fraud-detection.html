01 / BUSINESS CHALLENGE

The question behind the work.

Fraud detection is an imbalanced classification problem. A high overall accuracy can conceal poor detection of the rare class, making evaluation and decision thresholds central to the analysis.

02 / DATASET & OBJECTIVES

Start with the context.

A portfolio machine-learning project using transaction-classification data. The public tree includes train/validation/test CSVs, model artifacts and validation plots. Dataset provenance, licensing and the exact run behind each published metric need author confirmation.

Project objectives

  • Compare classical and neural-network approaches.
  • Explore resampling and Focal Loss for class imbalance.
  • Examine precision, recall and threshold-sensitive validation outputs.

03 / TECHNICAL APPROACH

How the pieces connect.

The repository includes data preparation utilities, configurable model training, Focal Loss code, neural-network and classical-model options, and evaluation helpers for confusion matrices and precision-recall curves.

ARCHITECTURE / DATA MODEL

Split transaction data → preparation/resampling → model training → threshold analysis → validation reports. The published code describes separate split inputs, but leakage-free execution and final test performance were not independently reproduced.

Implementation

PyTorch and scikit-learn support the modeling study. Configurations and evaluation code expose the chosen approach, while the original comparison heatmap shows a saved validation artifact rather than a production benchmark.

04 / VERIFIED OUTCOMES

What the work demonstrates.

The project demonstrates model-comparison and imbalance-handling techniques. The README, old portfolio and chart do not provide a single reconciled metric set; no headline F1/recall score or avoided-loss estimate is claimed.

Evidence & limitations

Public training/evaluation source and a retained validation comparison image. Model binaries were not loaded, training was not rerun, and this is not evidence of a live financial deployment.
